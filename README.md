Essa aplicação foi desenvolvida para simular um cardápio digital no qual você tando consultat as refeições disponíveis quanto adicionar novas. Foram usadas as extensões **Java Spring e Spring MVC**, **Spring Data JPA**, **Lombok**  e **Postgres Driver**.

<h2 id="pre-requisites">📍 Requisitos</h2> 

 - Uma IDE habilitada para rodar código em Java.
 - Banco de dados Postgres instalado na sua máquina.

<h2 id="how-to-use">📍Inicializando o Projeto </h2>

No terminal:

```bash
$ https://github.com/BrendaBraganca/cardapio-backend

# Para abrir com vscode
$ cd cardapio-backend
$ code .
```

<h2 id="related">📍 Tornando o projeto Fullstack</h2>

Para realizar a integração com o Frontend, você pode clonar o projeto e rodar localmente.
-  [Link do Frontend](https://github.com/BrendaBraganca/cardapio-frontend)
